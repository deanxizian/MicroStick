# MicroStick v1.0 UI previews

The PNG files in this directory are deterministic development previews for the 135×240 StickS3 layout:

- `home.png` and `home-usb.png`
- `home-battery-100.png`
- `voice-overlay.png`
- `control-center.png`
- `agent-menu.png`
- `navigation-menu.png`
- `usage-detail.png`
- `device-settings.png`
- `decline-confirm.png`
- `roxy-device-frames.png`
- `microstick-v1-ui-previews.png` composite

They are visual references, not substitutes for physical LCD acceptance. Final release verification must use the exact flashed firmware image.
